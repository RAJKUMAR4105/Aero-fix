# Approved Source Documents

Place text-based PDFs in this folder before ingesting. Use only current, approved
maintenance data for actual work. Useful public starting points include:

- Cessna 172 Pilot's Operating Handbook / AFM for the applicable serial number.
- Lycoming O-320 operator's manual and applicable maintenance publications.
- FAA Airworthiness Directives (ADs) applicable to the aircraft and engine.
- FAA Advisory Circular AC 43.13-1B (acceptable methods, techniques, and practices).

`SMOKE_TEST_ONLY.txt` is a non-approved test fixture. It must never be treated as
maintenance data.
